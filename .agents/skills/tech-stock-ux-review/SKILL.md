# TECH-STOCK UX Review

Use this skill to understand an existing screen before changing it.

Workflow:

1. Identify the actor and active role for the screen.
2. Identify the user's primary job and completion path.
3. Identify the primary action and whether it is visually discoverable.
4. Identify critical information required to act safely.
5. Review visual hierarchy, scanability, density, navigation and filters.
6. Review tables, forms, modals, drawers and row actions.
7. Check loading, empty, no-results, error and success states.
8. Check responsive behavior and accidental overflow.
9. When browser/Playwright MCP is available, inspect the real running screen and review a screenshot.
10. Prioritize recommendations as critical, high, medium and polish.

Prioritize task completion, reduced cognitive load, scanability and operational clarity. Do not use aesthetics as the only criterion.

Do not implement changes until the screen, role and workflow are understood.
